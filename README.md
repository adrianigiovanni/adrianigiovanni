# Giovanni Adriani

Network & telecom manager in retail, based near Lille, France. I started on the store helpdesk in
2006 and now look after the network of close to 1,000 sites (stores, head offices, warehouses) in
France and abroad. The last big project moved them from MPLS/ADSL/4G to SD-WAN/SASE, with new
Wi-Fi 7 access points and switches in every store.

At home I run a small lab that I treat like production: 21 servers, everything automated,
everything monitored.

- **Infrastructure:** Proxmox, Docker, OPNsense, TrueNAS
- **Automation:** Ansible, n8n, Python, Bash
- **Monitoring & logs:** Zabbix, OpenTelemetry, OpenObserve
- **Security:** single sign-on with Authentik, every secret in an Infisical vault
- **AI:** Claude Code as a day-to-day pair for ops, docs and small apps
